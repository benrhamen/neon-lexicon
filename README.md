# Neon Lexicon

An original neon English word game.

- Five different letters per draw. Letters can be reused without limit.
- Choose 1 minute, 2 minutes, 5 minutes or unlimited.
- Find unique words of at least three letters in the fixed ENABLE dictionary.
- Percentage = accepted words found / every accepted word for that draw × 100.
- One accepted word lights one pixel. The drawing contains exactly as many cells as there are possible words.
- Timer expiry or finding all possible words ends the round. Full completion earns "Congratulations, LEGEND!!!".
- Personal percentage rankings combine all draws and timers and are stored only in the current browser. Difficulty differs between draws. Clearing site data removes rankings. Storage failure falls back to session-only rankings with a visible warning.

No backend, accounts, analytics, payments or shared scoreboard. Personal practice scores are not verified competitive records.
